# browser_keywords_extension

<p align="center">
  <img src="public/icons/icon128.png" width="96" height="96" alt="browser_keywords_extension icon">
</p>

一个快捷键驱动的 Chrome 扩展：把「拖拽 / 点击 / 放大查看 / 取色 / 测距」这些重复动作绑定到单个按键上，按一下就能复现。所有配置按标签页独立保存，后续还会继续补充更多快捷功能。

## 功能

### 拖拽点击
录制按键 → 拾取起点 → 拾取终点，之后按该键自动重放一次鼠标拖拽（带缓动，可在设置里调时长、按下停顿、移动步数）。也支持「起点 = 当前鼠标」，即从鼠标所在位置拖到固定终点。

### 定点点击
录制按键 → 拾取位置，按该键在指定坐标点击一次。

### 区域点击
录制按键 → 框选一片区域，按该键按设定间距（默认 5px）在区域内逐点点击，适合批量点破气球、清空列表之类的高频操作。可调网格间距与点击间隔。

### 放大镜
录制按键（例如 Q）→ 按一下开启，再按一下（或 ESC）关闭。开启后一个 180×180 的镜片跟随鼠标，以鼠标为中心实时放大下方页面内容，倍数可在面板中调节（1.2 – 6，默认 2.4）。

- 实现方式是 DOM 镜像 + `transform` 缩放，每帧只做位移/缩放，60fps 跟手，不依赖截图权限。
- 页面 DOM 变化后会自动重建镜像；CSS 动画实时播放。
- 已知边界：`<canvas>`、`<video>` 里的画面不会被复刻。

### 取色
录制按键 → 按一下进入取色模式：先对当前视口截图，随后一个放大镜镜片跟随鼠标，中心十字准星对准待取像素，实时显示 HEX、RGB 与色块，取的是真实渲染像素（图片、canvas、视频画面都可以取）。

- `+` / `-`：实时调整放大倍数（2 – 24，默认 6），调整后回写为下次默认值，也可在面板中修改。
- 左键点击：复制 HEX 到剪贴板并关闭；右键 / ESC / 再按一次快捷键：取消。
- 取色画面为激活瞬间的冻结截图，取色期间锁定滚动，保证坐标对齐。

### 标尺测距
录制按键 → 按一下进入标尺模式（再按一次或 ESC 退出）。按住拖拽即可生成一条带刻度的标尺，中点标签显示长度，支持 px / mm 单位（mm 按 96px = 25.4mm 换算）。

- 多标尺并存，标尺跟随页面内容滚动；点击选中后高亮并显示角度，端点可拖拽微调、尺身可拖拽平移。
- 二级快捷键（作用于选中标尺，未选中则作用于最后一条）：

| 按键 | 功能 |
|------|------|
| Shift 拖拽 | 锁定 45° 倍数方向（含水平 / 垂直 90°） |
| S | 切换持续角度锁定 |
| R | 绕中点旋转 +15°（Shift+R 旋转 +90°） |
| D | 复制标尺 |
| Delete / Backspace | 删除选中 |
| U | px / mm 单位切换 |
| C | 清空全部 |
| ESC / 再按热键 | 退出标尺模式 |

### 高兼容模式
默认用页面内模拟事件，兼容大多数组件；遇到拖不动（原生 `draggable`）、点击无响应（文件、游戏等）时，打开「高兼容模式」，改由 `chrome.debugger` 派发真实输入事件。注意：该模式需要扩展的调试权限，且被调试的页面不能同时开着 DevTools。

### 界面深色模式
面板跟随浏览器 / 系统的深浅色主题自动切换，无需手动设置。

## 使用

1. 点击工具栏上的扩展图标打开面板，选择功能 tab（拖拽点击 / 区域点击 / 定点点击 / 放大镜 / 取色 / 标尺测距）。
2. 点「＋ 新建…」，按提示录制按键、拾取坐标或框选区域；放大镜、取色、标尺只需录一个按键。
3. 在页面上按对应按键即可执行；面板里可随时改键、改坐标、停用或删除。
4. 「全部启用」关闭后所有快捷键暂停响应；面板可拖动到任意位置，位置会记在本标签页。

## 测试页

项目根目录的 `test-page.html` 是一个功能测试页：方块可以拖进垃圾桶，泡泡可以用区域点击批量点破，也可以在这里验证放大镜、取色和标尺。

直接用 Chrome 打开这个文件（`file://`）即可，注意需要先在 `chrome://extensions` 中找到本扩展，进入「详情」并开启「允许访问文件网址」，否则 content script 不会注入本地文件页面。
